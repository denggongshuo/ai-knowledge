# O20 · 「需求 ↔ 后端枚举 ↔ mock 取值」的机器对账

> 状态：🟡 已登记（2026-09-20，`S8-M10-C` 认领）· 预估 ≈1.5 人天 · 优先级 **P1**
> 来源：`#164`（`S5-M08-C` 登记，`S8-M10-C` 触发）

---

## 1. 由来

`#164` 记的是一条**取值漂移**：

| 出处 | 「回答太啰嗦」那一档 | 「引用来源不对」那一档 |
|---|---|---|
| 需求 `07-需求-检索与问答.md:374` | 回答太**啰嗦** | 引用**来源不对** |
| 数据字典 `01-示例数据字典.md` §7.11 | 回答太**啰嗦** | 引用**来源不对** |
| 后端 `ChatFeedbackReason` | `TOO_VERBOSE("回答太啰嗦")` | `WRONG_CITATION("引用来源不对")` |
| 🔴 前端 `mock/data.ts:709-710` | 回答太**笼统** | 引用**不相关** |

**四方里三方一致，第四方（mock）独自漂着**，而 mock 正是 `render-check` / `console-check` / 开发时页面渲染的**取数源**。

🔴 **没有任何机器能发现它** —— 已核实：`audit-api.mjs` 的 ①/② 只比对**接口路径**（`前端调用 ↔ mock ↔ 文档`，见 `audit-api.mjs:8-9` 的口径），**不比对取值**。`ChatFeedbackReason` 的类注释里甚至**写了**这条漂移（"前端 mock 的展示串与之有漂移"），但**注释拦不住**——本仓对"只靠注释约定"这件事已有判例（`#202`/`#203`：新增 MinIO 前缀只有 javadoc 在管，漏一次 ⇒ 180 个孤儿）。

⇒ **这是「闸覆盖了路径、没覆盖取值」的首次显性化。** 与 `T-O15`（覆盖率闸只认精确列名）同族：**闸的射程与它的声明不一致**。

## 2. 做法（登记表 + 机器检查，抄 `ProbeArtifacts` 的形状）

| 步 | 做什么 |
|---|---|
| 1 | 新增 `scripts/lib/value-ledgers.mjs`：一张**登记表**，每行 = 一个「需求逐条列了取值」的闭集：`{ 后端枚举全限定名, 需求出处（文件:行）, mock 取值位置, 定位方式 }` |
| 2 | 新增 `scripts/check-enums.mjs`（或并进 `check-ledgers.mjs` 当第四组事实）：逐行**三方比对** —— ① 从 Java 枚举源码抽 `label` 字面量；② 从需求那一行抽列举项；③ 从 mock 抽取值数组。**只报不改**，退出码 `0/1/2` 分档（承既有约定） |
| 3 | **第一版只覆盖拿得出三处的那些**（不做通用解析器）：至少 `ChatFeedbackReason`（5 条）+ `MissStatus`（4 条）。登记表允许"暂未登记"，但**未登记且看起来像闭集**的要能报出来（那是覆盖率闸的半边，可选） |
| 4 | 收尾**证伪一次**：改 mock 里一条串 ⇒ 闸当场点名（这是它存在的唯一证明） |

⚠️ **不引依赖**：解析 Java 枚举用正则抽 `NAME("标签")` 已够（本仓先例：`check-ledgers.mjs` 就是纯正则 + 文件读）。

## 3. 判据

| # | 判据 | 方法 | 期望 |
|---|---|---|---|
| 1 | 登记表里每一行的三方取值**逐字相同** | `node scripts/check-enums.mjs` | exit `0`，0 处差异 |
| 2 | **证伪**：把 mock 的「回答太啰嗦」改回「回答太笼统」 | 同上 | exit `1`，**点名** `ChatFeedbackReason / TOO_VERBOSE` 与两处出处 |
| 3 | 需求文档那一行被改坏（列举项少一个） | 同上 | exit `1`（证明它比对的是**需求**，不只是 mock） |
| 4 | 前置不满足（文件不存在 / 解析不出枚举） | 同上 | exit `2`（**不是** `0` —— 承「退出码要分档」） |
| 5 | 本批的 `#164` 销账后，闸保持绿 | 同上 | exit `0` |

## 4. 明确不做

- **不做**通用 Javadoc/需求解析（那是"给文档写编译器"，长期成本远超收益）；
- **不做**对 `enum` 的**成员名**比对（成员名是内部标识，需求管不着它 —— 派不上用场的判据会变成噪声）；
- **不做**自动修（**只报不改**，与 `check-ledgers.mjs` 同一条纪律）。
