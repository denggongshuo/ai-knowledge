## 3. 开工内容

### 3.1 步骤

| 步 | 做什么 | 产出 |
|---|---|---|
| 1 | 设计**关系型语料**：实体跨文档多跳连通（系统↔负责人↔部门↔组件↔下游） | `graph-corpus.json`（8 篇 + 关系三元组） |
| 2 | 设计**分题型题集**：单跳 8 / 多跳 8 / 聚合 8，带 golden + mustNotRecall | `graph-queries.json`（24 题） |
| 3 | 写 A/B 用例：同一语料+同一嵌入，**图开/关**各跑一遍 | `GraphEvalTest`（`@Tag("graph-eval")`） |
| 4 | 输出分型 A/B 表：单跳差 / 多跳差 / 聚合差 + 合计 | 结论文档 |
| 5 | 按判据判定：单跳 ≤1pp · 多跳+聚合 ≥+10pp · 不足 5pp → 降级建议 | §8 结论 |

### 3.2 业务流程图

> 触发条件：跨 ≥3 组件（语料构造 → 建图 → 三路召回 → 融合 → 统计）+ 有 A/B 状态切换 ⇒ 画。

```mermaid
flowchart LR
  A[graph-corpus.json] --> B[注入分片 → Milvus 向量化]
  A --> C[构造 Anchored 关系 → GraphWriter 建边]
  B --> D{图开关}
  C --> D
  D -- 关 --> E[向量+BM25 → RRF]
  D -- 开 --> F[向量+BM25+图谱 → RRF]
  E --> G[Recall@5 分型统计]
  F --> G
  G --> H[单跳差 / 多跳差 / 聚合差 → G9-4 判定]
```

### 3.3 明确不做

| 不做的事 | 原因 |
|---|---|
| 让真模型抽关系（B 方案） | 抽取波动会污染 ±1pp/+10pp 精度；抽取质量另有 `RelationAnchorRateProbeTest` |
| 复用 `T-711` 表格语料 | 表格题考不出图谱价值（假阴性） |
| 页面级 E2E | G9-4 是**检索质量**门禁，评的是 Recall@5 差值，不是页面渲染 |

### 3.4 本批假设

| # | 假设 | 若被证伪的后果 |
|---|---|---|
| 1 | 手写关系三元组能真实建边（实体名在正文里） | 锚不上 ⇒ 图谱零召回 ⇒ A/B 无差异；用"图里边数>0"断言守住 |
| 2 | 多跳题在纯向量/BM25 下确实召不到（答案 chunk 无查询词） | 若向量也召到 ⇒ A/B 差≈0，说明题设计不够"跨文档"；需重设计题 |
| 3 | 缺省 24 题规模下 ±1pp/+10pp 有区分度 | 题量不足则噪声大；必要时扩到 30+ |
